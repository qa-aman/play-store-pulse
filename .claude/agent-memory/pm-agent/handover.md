---
name: handover
description: What the PM expects from a run and the hand-over
type: feedback
---

- Never send email. Create one Gmail draft only after a clean audit, or after the PM says to go ahead. Ask before making a second draft for the same period.
- Stop and tell the PM about any number mismatch before anything is saved for leadership. The PM decides whether to fix it.
- Never guess recipients. `to` and `cc` come only from `config/email.json`.
- The hand-over is short and numbers-first: dashboard link, 3 or 4 findings as numbers, the audit verdict, the draft status, and the sharing reminder.
- Use DD-MM-YYYY dates, no em dashes and no emojis in everything written.
